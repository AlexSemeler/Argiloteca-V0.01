# Logos das fontes — administração local

Arquivos obtidos em 31/10/2026 exclusivamente de páginas oficiais para identificar as fontes e a ferramenta de identidade. As marcas preservam sua aparência; não indicam patrocínio, certificação ou parceria.

- OpenAlex: https://openalex.org/brand-assets/openalex-lockup.png — https://blog.openalex.org/a-new-logo-for-openalex/
- PANGAEA: logo do cabeçalho de https://www.pangaea.de/ (URL versionada em `sources.json`).
- Mendeley Data: SVG inline `mdui-logo` do cabeçalho de https://data.mendeley.com/. Extração integral da marca; apenas adicionado o namespace SVG para uso como imagem independente.
- LUME UFRGS: https://lume.ufrgs.br/themes/Mirage2Novo/images/logo_lume.png
- UFSC: brasão do Sistema de Identidade Visual, https://identidade.ufsc.br/wp-content/themes/brasilGovInterno/img/brasao_site_ufsc.svg — https://identidade.ufsc.br/
- ORCID: https://info.orcid.org/wp-content/uploads/2021/01/orcid-logo.png — https://info.orcid.org/brand-guidelines/

`sources.json` registra origem, data, transformações e hashes. Os quatro PNGs também contêm a origem em metadados tEXt; pixels preservados, sem geração ou recoloração. Os SVGs são servidos como imagens locais e não contêm scripts ou foreignObject. A referência ontológica enviada pelo usuário orienta a navegação, sem se tornar uma imagem textual na interface.
